## 为什么做这个

因为没钱充会员用todesk老被踢，化身愤怒的普通人，直接做了个简易的远程登录软件，免费且可自定义，可以用AI再根据自己的要求进行修改，画质目前最高支持1080p+144hz，只加了简单的文件拖拽能力，目前还未加入隐私屏、一键开机、双端剪切板互通等等功能，可以自己DIY，平时我得玩游戏看论文做实验，只能随缘更新

这个小工具叫 **TwinLink**，目前是 **1.3.1 预览版**，已经开源。

- [GitHub 源码仓库](https://github.com/lx23333333/twinlink-remote)
- [Windows 下载页面](https://github.com/lx23333333/twinlink-remote/releases/tag/v1.3.1)
- [直接下载 TwinLink-Windows.zip](https://github.com/lx23333333/twinlink-remote/releases/download/v1.3.1/TwinLink-Windows.zip)

## 现在能做什么

适用于两台 Windows 10/11 x64 电脑，可以交换控制方向，也可以跨网段连接。默认请求 **1920×1080、144 FPS、50 Mbps**，支持远程键鼠操作和音频。

这里的 1080p / 144 Hz 是当前界面的目标参数，实际能跑多少帧，仍然取决于两端显卡、显示器模式和网络。还没有完成真实双机的 144 FPS 性能验收。

文件功能会随远程连接自动准备，不需要另开助手或手动填写同步口令。目前可以把本机文件拖入远程画面，复制到对方当前打开的文件夹或桌面；同名文件会加编号，保留原文件。暂不支持直接拖到聊天软件、浏览器或文件夹图标里，文件夹需要先压缩。

也有预览版的文件复制同步：复制文件后，等待就绪通知，再到另一端粘贴。完整的双端文本、图片等剪贴板互通还没做。文件拖拽和复制的真实双机交互仍需继续验证。

1.3.1 修复了游戏中长按鼠标左键可能误弹文件传输遮罩的问题，改为只响应真正的文件拖放；黄色性能参数也默认关闭。

## 怎么用

1. 在两台电脑下载并完整解压压缩包，运行里面的 `TwinLink.exe`。
2. 点击“安装三个必要组件”，安装 Sunshine、Moonlight 和 Tailscale。
3. 两台电脑登录同一个 Tailscale 账户，按界面提示配置 Sunshine 账户，并完成首次 PIN 配对。
4. 在控制端填入对方的 Tailscale IP，应用名称保持 `Desktop`，点击“连接远程桌面”。另一台反过来控制时，交换方向并完成对应配对。

文件功能还需要在 Tailscale 中启用 Send Files，并保持两端 TwinLink 运行。首次运行可能需要允许程序配置文件连接的网络权限，详细步骤和排错方法都放在仓库 README 里。

升级时请先右键系统托盘里的 TwinLink，选择“退出 TwinLink”，再启动新版。只关闭主窗口会留在托盘。退出远程画面的快捷键是 **Ctrl + Alt + Shift + Q**。

## 实现方式与后续

这个项目把 Sunshine 的画面采集与编码、Moonlight 的显示与远程输入，以及 Tailscale 的跨网连接组合到一个中文界面里。TwinLink 自己负责组件安装入口、连接参数和会话文件功能，压缩包不捆绑第三方组件。

自有代码采用 **MIT 许可证**，可以免费使用、修改和分发。第三方组件及服务仍适用各自的许可和条款。

目前还没有隐私屏、远程开机和完整的双端剪贴板互通，也不能在被控电脑关机时直接连接。110 项本地检查已经通过，但本地测试不等于真实双机体验已经全部验收，具体范围见仓库里的 [验证记录](https://github.com/lx23333333/twinlink-remote/blob/main/docs/VALIDATION.md)。

想加功能可以直接拿源码 DIY，也可以把项目交给 AI，按自己的需要继续改。我这边随缘更新。
